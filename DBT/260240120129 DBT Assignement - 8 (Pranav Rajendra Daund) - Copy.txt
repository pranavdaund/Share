Q3) Create a collection named products.

a) Find all products in the “Electronics” category.

		db.product.find({category: "Electronics"});


b) Show only name and price of products where price is greater than 5000.

		db.product.find(
		{ price: { $gt: 5000 } },
		{ name: 1, price: 1 }
		);


c) Count how many products are in the “Furniture” category.

		db.product.countDocuments({ category: "Furniture" })
